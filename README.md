
# Patient Readmission Prediction 

## Objective
Predict whether a patient will be readmitted using machine learning models.

## Steps Performed
- Data cleaning & preprocessing
- Feature engineering (RiskScore)
- OneHot Encoding
- Standard Scaling
- Model training (Logistic Regression & KNN)
- Model evaluation (Accuracy, Precision, Recall, F1, ROC, AUC)

## Models Used
- Logistic Regression
- K-Nearest Neighbors (k=7)

## Tools
- Python
- Pandas
- Scikit-learn
- Matplotlib
